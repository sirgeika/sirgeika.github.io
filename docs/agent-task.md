## 3. Критерии фильтрации (Scoring & Rules)

### Безусловный пропуск (Blacklist / Disqualifiers):
1. **Языковой барьер:** Вакансии, требующие свободного беглого разговорного английского (C1/C2 / «fluent business English as main office language») при отсутствии немецкого, ЛИБО требующие строго немецкого C1/C2 для клиентской/консалтинговой работы.
2. **Нерелевантный стек:** Вакансии строго под Angular или React без присутствия Vue.js в стеке, либо чистый Mobile (iOS/Android Native).
3. **Требование позиции Team Lead:** Роли уровня *Head of Engineering* или классического *Engineering Manager* (кандидат не претендует на чисто руководящие роли из-за языка).
4. **Визовые ограничения:** Компании, требующие исключительно гражданства ЕС (например, закрытые оборонные контракты).

### Приоритетные цели (Whitelist / Target Match):
- **Приоритет 1 (Идеальное попадание):** Немецкие продуктовые и средние IT-компании (Mittelstand), системные интеграторы в Штутгарте, где технический стек — **Vue.js / Node.js**, а рабочий язык внутри команды — **немецкий (уровень B1/B2)** или смешанный с лояльными требованиями к языку.
- **Приоритет 2:** Вакансии в сфере транспорта, логистики, бронирования, авиации или CAD/инженерного ПО (прямой доменный опыт кандидата: ORS TWT/DCS, CAD-редакторы).
- **Приоритет 3:** Компании, внедряющие Web-интерфейсы с элементами AI / LLM или чат-ассистентов (опыт с lingvochat.com, Firebase, Genkit).

## 4. Алгоритм работы агента (Step-by-Step Execution)

1. **Сбор данных (Scraping/API Search):**  
   Запуск поисковых запросов по ключевым словам:
   - `Frontend Entwickler Vue Stuttgart`
   - `Vue.js Entwickler Baden-Württemberg`
   - `Fullstack Entwickler Node.js Vue Stuttgart`
   - `Webentwickler Vue.js Homeoffice`
2. **Семантический анализ текста вакансии:**  
   - Проверка требований к стеку (наличие Vue 2 / Vue 3 / JavaScript / TypeScript).
   - Проверка языковых требований (подходит ли под B1 немецкий / чтение на английском).
3. **Скоринг вакансии (от 0 до 100):**  
   - Стек Vue/Node: +40 баллов.
   - Локация (Штутгарт / Remote): +20 баллов.
   - Адекватные требования к языкам (German B1-B2 friendly): +20 баллов.
   - Доменная близость (Enterprise, Aviation, B2B platforms, CAD, AI): +20 баллов.
4. **Генерация артефактов по отобранным позициям:**  
   Для вакансий с баллом **75+**:
   - Сформировать карточку вакансии.
   - Сгенерировать короткое индивидуальное немецкое сопроводительное письмо (3–4 абзаца *Anschreiben*) с упором на то, как опыт кандидата закрывает задачи работодателя.

## 5. Формат выходного отчета агента (Output Schema)

По каждой подходящей вакансии формируется запись:

| Поле | Описание / Пример |
| :--- | :--- |
| **Компания & Должность** | Название работодателя, точный тайтл вакансии |
| **Локация & Формат** | Город (напр. Stuttgart-Vaihingen), Hybrid (1-2 дня офис) / Remote |
| **Стек технологий** | Перечисление основного стека из текста объявления |
| **Языковые требования** | Язык вакансии и заявленные требования (DE / EN) |
| **Почему подходит (Match Reason)** | 2–3 пункта сопоставления с опытом кандидата (Vue, Enterprise, ORS, AI) |
| **Потенциальные риски** | Например: *«Упомянут TypeScript, требуется подтянуть терминологию на немецком»* |
| **Ссылка на отклик** | Прямой URL на вакансию |
| **Готовый Anschreiben-Pitch** | 1 короткий абзац для поля "Cover Letter" или сопроводительного письма |
